# Sources

Every fact on this site cites a source with a URL and a retrieval date. This file records what each source is, its
terms, what it is used for, and whether it meets the source bar. The bar is: peer-reviewed papers, Nobel citations, or
government and institutional data (USGS, NIST, DOE, NASA, EIA, NLM, IUPAC). Wikipedia, blogs, news articles, wikis
and video are not citations.

Facts are not copyrightable. A citation records where a fact came from. Text on this site is written by us, not copied
from a source. A quotation is included only when copied word for word, and it is marked as such.

## How to add a source

1. Record the URL, the publisher, the terms of use, and the date you read it.
2. Check the source is on the list of acceptable kinds above. If it is not, do not add it.
3. If the source is copyrighted, cite it by link and record facts only. Do not copy text.
4. Add a row to this file in the same change as the data.
